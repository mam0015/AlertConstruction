Alert request flow preview

Open this page first:
request-a-job/index.html

Included pages:
- request-a-job/index.html: customer request panel
- request-form/index.html: customer form
- project-status/index.html: project situation page
- worker-update/index.html: workers-only update preview for admin, owner and manager

When the customer submits the form, the preview creates a private code like:
ATP-260803-N9US

The customer project situation page does not show the worker update form. The
worker update form is separated for admin, owner and manager.

The preview stores requests in the browser only. For the real live website, a
login plus database/backend is needed so workers and customers can see the same
updated project situation from different devices.
