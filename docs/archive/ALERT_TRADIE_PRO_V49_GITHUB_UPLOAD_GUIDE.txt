FINANCIAL DATA
--------------
The existing Financial Data section remains in the Operation Hub left sidebar.
Its sections are:

- Overview
- Income
- Expenses
- Project Budgets
- Approvals
- Finance Access

Users enter revenue, payments, expenses, committed costs and budget data in
these sections. The Finance page recalculates cash flow, revenue vs expenses,
expense categories and project profitability. Approved data also updates the
authorised Finance cards and Finance Summary on the Operation Hub Overview.


ROLE-AWARE HOME AND NAVIGATION
------------------------------
- Home tool cards are now filtered by the signed-in active role.
- The top Tools menu uses the same permission matrix.
- Empty tool categories are hidden.
- Category filters cannot reveal a tool outside the current role.
- The Home page states which role is active and how many tools are available.
- Project Photo Timeline is now included as a Home tool for authorised roles.
- The global Reports link now opens the real Work Management Reports page.
- Deep-link protection and Supabase Row-Level Security remain unchanged.

Verified Home visibility:

- Owner: all 14 public tool cards.
- Estimator: 12 estimating, analysis, project, invoice, assigned-budget and
  view-only Photo Timeline tools.
- Project Manager: 6 project, site and business tools.
- Site Supervisor: 4 assigned-project and site tools.
- Worker: own finance-claim entry from Home, plus Operation Hub / Reports
  navigation for personal work records.

Finance applies a second permission layer after the menu opens:

- Owner: full company dashboard, transactions, budgets, approvals and access.
- Admin: only the finance permissions enabled by the Owner.
- Manager: authorised assigned-project commercial information.
- Estimator: assigned-project budget / estimate values without company profit
  or transaction management.
- Site Supervisor and Worker: their own expense submissions only.
