ALERT TRADIE PRO V52 — COMPLETE PUBLIC + PRIVATE PACKAGE
========================================================

This release combines the complete, latest Alert Tradie Pro V52 files.

PACKAGE CONTENTS
----------------

1. PUBLIC-WEBSITE/
   Complete GitHub Pages website files.

2. PRIVATE-SUPABASE/
   Supabase migrations, configuration, deployment notes, and the latest
   analyse-plan Edge Function source.

IMPORTANT SEPARATION
--------------------

- Upload only the contents of PUBLIC-WEBSITE to the GitHub repository root.
- Never upload PRIVATE-SUPABASE to GitHub Pages or any public website folder.
- Keep the private folder as the backend/deployment copy.

PUBLIC WEBSITE INSTALLATION
---------------------------

1. Unzip the complete package.
2. Open PUBLIC-WEBSITE.
3. Upload its contents to the GitHub repository root, preserving every folder.
4. Replace matching files.
5. GitHub's browser uploader accepts no more than 100 files at once. Upload the
   public files in two batches if you use the browser interface.
6. Wait for GitHub Pages to finish deploying.
7. Close old app tabs, open a private/incognito window, and hard-refresh.
