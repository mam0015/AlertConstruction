ALERT TRADIE PRO V44 — OPERATION HUB FINANCIAL DATA
COMPLETE GITHUB WEBSITE PACKAGE
===================================================

PACKAGE PURPOSE
---------------
AlertTradiePro-V44-WEB-PUBLIC-FINAL.zip is the complete public web app.
It is based on the verified full V43 package and includes the V44 Operation
Hub and Financial Data update.

Copy the complete contents of this package to the ROOT of the existing
mam0015/AlertConstruction GitHub repository. This is not a partial patch.


WHAT V44 ADDS
-------------
- Grouped Operation Hub navigation for Overview, Projects & Site,
  Commercial & Finance, Team, and Documents & Reports.
- Mobile Operation Hub menu that opens as an overlay drawer.
- Financial Data landing page with clickable summary cards.
- Cash In, Cash Out, Net Cash Flow, Outstanding Invoices and Forecast Profit.
- Cash-flow line chart using actual payment dates.
- Income-versus-expenses chart using earned/incurred transaction dates.
- Expense category donut chart.
- Project budget, committed cost, cost-to-complete and profit forecasts.
- Income and expense Draft, Pending Approval, Approved, Rejected and Voided
  workflows.
- Multiple dated payment records for accurate cash-flow reporting and partial
  payment balances.
- Receipt and PDF attachments through private Supabase storage.
- Duplicate supplier/customer transaction detection.
- Owner-controlled optional Admin finance access and approval limits.
- Australian financial-year reporting and GST-exclusive management figures.
- CSV export for authorised roles.
- Existing Alert Tradie Pro logo and brand text; no replacement logo.


DATA AND BACKEND COMPATIBILITY
------------------------------
V44 keeps the existing:
- GitHub Pages path: /AlertConstruction/
- public Supabase URL and publishable/anon key configuration

ROLE ACCESS SUMMARY
-------------------
Owner
  Full company dashboard, all projects, budgets, transactions, approvals,
  audit-safe voids, exports and Admin finance permission management.

Admin
  No finance access by default. The Owner can enable the dashboard,
  transactions, budgets, approvals, exports and an approval limit separately.

Manager
  Assigned projects only. Can create assigned-project income/expense drafts,
  view assigned budgets and export assigned transaction reports. Cannot see the
  company dashboard or approve entries.

Estimator
  Read-only assigned-project estimate and forecast values. Cannot see actual
  cost, company profit, transactions or approvals.

Site Supervisor
  Can submit and track only their own expense claims on assigned projects.

Worker
  Can submit and track only their own expense claims on assigned projects.

Permissions are enforced by Supabase RPC functions and Row-Level Security, not
only by hidden buttons.

ROLLBACK
--------
If the website deployment needs to be rolled back, restore the previous GitHub
commit or Pages deployment. Leave the additive V44 finance tables and private
bucket installed; older public files do not use them. Do not delete finance
records or receipt objects as a rollback method.
